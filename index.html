01 Variáveis e Escopo

Conceito: Variáveis são espaços alocados na memória para guardar dados temporários. Usamos const (imutável) e let (mutável). var caiu em desuso por problemas de escopo.

🌍 Assimilação Real

Pense no inventário de um jogo. const: É a sua classe de personagem (Você escolheu Mago, não pode mudar no meio da partida). let: É a sua barra de HP (Pode subir ao tomar poção ou descer ao levar dano).

aula01.js 
// A classe nunca muda
const classe = "Mago";

// O HP é dinâmico
let hp = 100;
hp = hp - 30; // Tomou dano, agora é 70

console.log(`Classe: ${classe} | HP Atual: ${hp}`);
$ node aula01.js Classe: Mago | HP Atual: 70

02 Tipos e Operadores

Conceito: O JS não é fortemente tipado (por isso usamos TypeScript depois). Se você somar uma string com número, ele concatena (junta). Operadores matemáticos (+ - * / %) seguem a precedência da matemática.

🌍 Assimilação Real

Se a API do jogo te manda o dano como texto "50" e você soma com a defesa 20, o jogador vai levar "5020" de dano e bugar o servidor. Sempre converta com Number().

aula02.js 
const danoString = "50"; // Veio da API
const defesa = 20;

// A armadilha:
console.log(danoString + defesa); // "5020" (Bug!)

// A solução: Converter e calcular
const danoReal = Number(danoString) - defesa;
console.log(danoReal); // 30
$ node aula02.js 5020
30

03 Controle de Fluxo (Condicionais)

Conceito: O cérebro do código. Usamos if (se), else if (senão, se) e else (senão). Combinados com operadores lógicos: && (E) e || (OU).

🌍 Assimilação Real

Matchmaking: Para entrar numa partida ranqueada, o jogador precisa ter Nível >= 10 E (&&) ter o jogo original comprado. Se ele não cumprir, cai no else e recebe um bloqueio.

aula03.js 
const nivel = 15;
const temJogoOriginal = true;

if (nivel >= 10 && temJogoOriginal) {
    console.log("✅ Entrando na fila Ranqueada...");
} else {
    console.log("❌ Acesso negado. Jogue Casual primeiro.");
}
$ node aula03.js ✅ Entrando na fila Ranqueada...

04 Loops (A Repetição)

Conceito: Automação. O for itera um número conhecido de vezes. O while roda até a condição falhar. O for...of é usado para percorrer listas.

🌍 Assimilação Real

Imagine que você precisa spawnar 5 inimigos em um mapa de tower defense. Em vez de escrever `spawnarInimigo()` 5 vezes, você usa um loop for que chama a função 5 vezes de forma automática.

aula04.js 
// Loop para contar inimigos restantes
for (let i = 1; i <= 3; i++) {
    console.log(`Inimigo ${i} spawnado na arena!`);
}
$ node aula04.js Inimigo 1 spawnado na arena!
Inimigo 2 spawnado na arena!
Inimigo 3 spawnado na arena!

05 Funções (As Máquinas)

Conceito: Funções são blocos de código que só rodam quando chamados. Elas podem receber parâmetros e devolver um valor com return. Arrow functions (=>) são a forma moderna.

🌍 Assimilação Real

Uma função é como a fórmula de dano do LOL ou CS. Você passa os atributos (Ataque, Defesa do alvo) e a função processa, aplicando a matemática, e te devolve o dano final. Se você mudar a fórmula, muda em um lugar só.

aula05.js 
// Arrow function para calcular dano crítico
const calcularDano = (ataque, multiplicador) => {
    return ataque * multiplicador;
};

const danoCritico = calcularDano(100, 2.5); // 100 base, 2.5x crítico
console.log(`💥 Dano Crítico: ${danoCritico}`);
$ node aula05.js 💥 Dano Crítico: 250

06 Arrays (Listas de Dados)

Conceito: Estruturas indexadas (começam no 0) que guardam múltiplos valores. Métodos essenciais: .push() (adicionar), .pop() (remover final), .length (tamanho).

🌍 Assimilação Real

O array é o inventário do jogador. O item no index 0 é a primeira arma. Quando você pega um novo loot, você dá um .push(). Se o inventário enche (atinge o .length máximo), você precisa dropar algo.

aula06.js 
const inventario = ["Faca", "Pistola"];
inventario.push("Rifle"); // Adiciona no final

console.log(`Itens: ${inventario}`);
console.log(`Primeiro item: ${inventario[0]}`);
$ node aula06.js Itens: Faca,Pistola,Rifle
Primeiro item: Faca

07 Objetos (Entidades)

Conceito: Agrupam propriedades (chave-valor). São a representação de entidades do mundo real no código (um Jogador, uma Arma, uma Partida). Acessados via obj.chave.

🌍 Assimilação Real

Uma API de jogo não te devolve o jogador como um array solto. Ela te devolve um Objeto: { id: 1, nome: "Faker", elo: "Desafiante" }. O objeto tem nome para cada informação.

aula07.js 
const jogador = {
    nick: "Faker",
    funcao: "Mid",
    campeao: "Azir"
};

console.log(`O jogador ${jogador.nick} joga de ${jogador.funcao} com o ${jogador.campeao}.`);
$ node aula07.js O jogador Faker joga de Mid com o Azir.

08 Higher-Order Functions

Conceito: O segredo do backend moderno. .map() transforma um array em outro. .filter() cria um novo array apenas com os itens que passam num teste. .reduce() transforma o array em um único valor.

🌍 Assimilação Real

Se você tem a lista de todos os jogadores da partida, o .filter() é o que a Riot usa para pegar apenas os jogadores que deram "Report" por cheat. O .map() é usado para pegar apenas os nomes (strings) desses jogadores.

aula08.js 
const jogadores = [
    { nome: "Ana", kda: 1.2 },
    { nome: "Hacker", kda: 15.0 } // Suspeito!
];

// Filtra jogadores com KDA maior que 10
const suspeitos = jogadores.filter(j => j.kda > 10);

// Pega apenas os nomes dos suspeitos
const nomesSuspeitos = suspeitos.map(j => j.nome);

console.log(nomesSuspeitos);
$ node aula08.js [ 'Hacker' ]

09 Try/Catch (Gestão de Erros)

Conceito: Se um erro ocorrer, o programa inteiro não pode cair. O try tenta rodar o código. Se der erro, o catch intercepta e evita o crash. Usamos throw new Error() para forçar um erro.

🌍 Assimilação Real

Você está lendo um arquivo JSON de save do jogo. Se o arquivo estiver corrompido, sem o try/catch o servidor cai (DDoS acidental). Com o try/catch, ele lê, vê que deu erro, e retorna uma mensagem amigável pro jogador.

aula09.js 
function comprarItem(preco, saldo) {
    if (preco > saldo) {
        throw new Error("Saldo insuficiente para compra!");
    }
    return "Compra realizada";
}

try {
    comprarItem(500, 200);
} catch (erro) {
    console.log(`❌ Falha: ${erro.message}`);
}
$ node aula09.js ❌ Falha: Saldo insuficiente para compra!

10 Async / Await (Promises)

Conceito: O JavaScript não espera requisições terminarem (single-thread). Se você buscar dados do banco, o código continua rodando. O await pausa a função async até a Promise retornar sucesso ou falha.

🌍 Assimilação Real

Quando você clica em "Entrar na Partida", o servidor da Riot precisa verificar seu login, seu elo, e te alocar numa sala. Isso demora 1-2 segundos. O navegador não pode congelar. Ele segura a requisição com await, e o resto do site continua clicável.

aula10.js 
// Simula uma API lenta
function buscarRanking() {
    return new Promise(resolve => {
        setTimeout(() => resolve({ elo: "Desafiante", pontos: 1200 }), 1500);
    });
}

async function carregarPerfil() {
    console.log("Buscando dados na API...");
    const dados = await buscarRanking(); // Pausa aqui e espera 1.5s
    console.log(`Elo: ${dados.elo} | LP: ${dados.pontos}`);
}

carregarPerfil();
$ node aula10.js Buscando dados na API...
(espera 1.5s)
Elo: Desafiante | LP: 1200
