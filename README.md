## 📚 O que é abordado neste Repositório?

O material foi estruturado para levar do absoluto zero até a preparação para o assincronismo (comum em APIs e bancos de dados). Para facilitar o aprendizado, cada tópico conta com **conceito teórico**, **analogias do mundo real** (usando contextos de jogos), **código comentado** e **outputs do terminal**.

### Fundamentos Cobertos:
*   **01. Variáveis e Escopo:** `const`, `let` e a importância do escopo.
*   **02. Tipos e Operadores:** Strings, Numbers, Booleans, precedência matemática e conversão de tipos (armadilhas clássicas).
*   **03. Controle de Fluxo:** `if`, `else if`, `else` e operadores lógicos (`&&`, `||`).
*   **04. Loops (Repetição):** `for`, `while` e `for...of` para automação de tarefas.
*   **05. Funções:** Parâmetros, `return`, arrow functions (`=>`) e composição de máquinas lógicas.
*   **06. Arrays:** Estruturas indexadas, `.push()`, `.length` e manipulação de listas de dados.
*   **07. Objetos:** Agrupamento de chave-valor, entidades do mundo real e notação de ponto.
*   **08. Higher-Order Functions:** O segredo do backend moderno (`.map()`, `.filter()`, `.reduce()`).
*   **09. Tratamento de Erros:** `try/catch` e como evitar que o servidor caia (crash) por falhas inesperadas.
*   **10. Assincronismo:** `Promises`, `async` e `await` para lidar com requisições HTTP e banco de dados de forma não bloqueante.
