# Backend Foundations: JavaScript & TypeScript 🚀

Repositório dedicado ao domínio dos fundamentos de programação, lógica e arquitetura backend. 

Este projeto documenta minha transição de carreira (de Engenharia Química para Desenvolvimento de Software), focando na base sólida necessária para construir sistemas escaláveis, APIs e futuramente atuar com análise de dados para infraestrutura de jogos.

## 📁 Estrutura do Repositório

* **`01-aulas/`**: Códigos teóricos super comentados (de variáveis a assincronismo).
* **`02-exercicios/`**: Resolução dos desafios práticos de cada tópico.
* **`03-projetos/`**: (Em breve) API de estatísticas de jogos com Node.js, Fastify e Prisma.

## 🧠 Tópicos Dominados
- Variáveis, Tipos de Dados e Operadores
- Estruturas Condicionais e Laços de Repetição
- Funções e Escopo
- Manipulação de Arrays e Objetos
- Higher-Order Functions (`.map`, `.filter`, `.reduce`)
- Tratamento de Erros (`try/catch`)
- Programação Assíncrona (`Promises`, `async/await`)
